# Examples

`athenspop` is a collection of composable tools rather than one prescribed pipeline. Start with the generic composition patterns for validation, one-off scheduling, repeated generation, or exploratory sequence clustering. The Athens paper-result reference and migrated reanalysis are one maintained dataset-specific composition.

Dataset policy stays outside the generic package. The Athens pages are included from `examples/athens/docs` so the executable workflow and published documentation share one source.
